# gld-kiln-csharp

A from-scratch Kiln codec for C#. The package is `Gld.Kiln`. The namespace is `Kiln`. The generator command is `gld-kilngen-csharp`.

The library encodes and decodes Frozen values and a version-2 tensor directory. It does not wrap another Kiln implementation.
